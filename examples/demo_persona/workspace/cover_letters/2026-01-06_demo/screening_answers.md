## Describe a project where you evaluated a model. (limit: 120 words)

> Because I wanted to know whether a smarter search would actually help, I tested it. In a natural language processing
> course project, the question was whether a retrieval-based assistant could answer a university library's common
> questions better than keyword search. I built the retrieval pipeline in Python with sentence embeddings and a FAISS
> index over 85 FAQ pages, then scored both approaches on 60 questions I wrote myself: 41 correct with embeddings
> against 29 with keyword search. The test set was small and judged by me alone, so I treat it as a course experiment.
> On your team I would write the evaluation code first, so every later change can be compared against the same baseline.

## Why are you interested in this role? (limit: 80 words)

> I am passionate about building systems like this for a team that is turning information into decisions. The library
> assistant used FAISS and sentence embeddings and reached 41 of 60.
